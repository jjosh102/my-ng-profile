# Josh Piluden

Personal site built with Angular. The page is intentionally static so the introduction and featured work remain available without a third-party API.

Bayadak and Buyaek lead selected work with direct app links, visible domains, and separate project notes on jjosh.dev. The hero also links to both apps. Keep the showcase readable at 320px, tablet, and desktop widths in both themes, with visible keyboard focus. Bagiyo's screenshot dialog remains below the apps; the print layout includes their domains.

Run `npm ci` and `npm start` locally. Run `npm run build` to check the production bundle. The GitHub Pages workflow deploys changes to `master`.
