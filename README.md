# Josh Piluden

Personal site built with Angular. The page is intentionally static so the introduction and featured work remain available without a third-party API.

Bayadak and Buyaek lead selected work with direct app links, visible domains, and separate project notes on jjosh.dev. The hero also links to both apps. Keep the showcase readable at 320px, tablet, and desktop widths in both themes, with visible keyboard focus. Selected work comes before the background section, and navigation follows that order. Its full-width grid gives each app a distinct header with its category, name, domain, and decorative SVG icon. Bagiyo uses a separate copy-and-preview layout below the apps; its native screenshot dialog and the printable app domains are preserved.

Resources use plain links for notes and guides rather than another card grid. Contact makes the address prominent, with separate copy and print actions and an announced clipboard result. Preserve these controls, selectable text, and printed resource URLs when changing the layout.

Run `npm ci` and `npm start` locally. Run `npm run build` to check the production bundle. The GitHub Pages workflow deploys changes to `master`.
